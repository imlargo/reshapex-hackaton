 Table of Contents

 SICK Nova can be extended with new tools developed as Nova plug-ins. This page provides a starting point for users who want to do custom Nova Tool development.

 Prerequisites for Nova Custom tool development training 

 A computer with the latest version of SICK AppManager and SICK AppStudio installed 

 The latest version of SICK AppEngine installed.( If you have a SICK Inspector device, you can use that instead of AppEngine.) 

 The latest version of Nova Inspector app installed on the AppEngine or Inspector. It can be downloaded from AppPool. 

 The latest version of Nova Tool API downloaded from below and kept ready. 

 The latest version of Chrome installed. 

 SICK Nova Tool API 

 The SICK Nova Tool plug-in API documentation contains:

 A guide on how to use the API to create new tools for Nova.

 The Tool API reference.

 AppSpace Crown API: Documentation for the subset of SICK AppSpace Crowns used within the Nova Tool API.

 The Tool Generator application and instructions on how to use it to create a skeleton structure for a new tool.

 Note: The API version (eg. 2.9.0) is distinct from the Nova version (eg 2.11.0) . Multiple Nova releases may use the same API version. The API version included in a specific Nova release is shown in the about dialog with label “Nova API version”.

 SICK Nova Sample Tools 

 By going to SICK AppPool and searching for sample tool you will be able to find example tools with open code. This means that you can open the tool in SICK AppStudio and find the full code for the tool.
