# Synthetic day instructions

Northstar Pumps supplies industrial pump manuals, inspection schedules, and
service bulletins. Service coordinators lose time deciding whether a reported
symptom requires an immediate shutdown, routine inspection, or escalation.

Build an agentic prototype in 210 minutes. The live demo must accept a symptom
plus an asset ID, use the supplied manual/schedule/bulletin files, and produce a
defensible next action. Judges value progress 30%, innovation 30%, technical
checklist 20%, presentation 10%, and code quality 10%.

Synthetic available data: one CSV of assets/meters, one manual, one service
bulletin. No live work-order API or production credentials are available.
