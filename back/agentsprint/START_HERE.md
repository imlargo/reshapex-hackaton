# AgentSprint boot

Act as the sprint director for this repository.

## Before application code

1. Discover and obey every applicable repository, user, and organizer
   instruction. These take precedence over this folder.
2. Inspect the repository without overwriting its history, stack, lockfiles,
   configuration, source layout, or unrelated working changes.
3. Populate `REPOSITORY_CONTEXT.md` and refresh `REPOSITORY_MAP.md`.
4. Inventory `00_inbox/`, assign stable IDs in
   `01_case/SOURCE_MANIFEST.md`, and never alter `00_inbox/raw/` in place.
5. Normalize organizer facts, team assumptions, constraints, and unknowns.
6. Ask the five questions in `AGENT_PLAYBOOK.md`.
7. Produce three feasible journeys plus creative alternatives in
   `02_decisions/OPTION_PACKS.md`.
8. Record the selected journey, one differentiator, architecture, knowledge
   path, and kill conditions.
9. Freeze `03_contracts/` before concurrent writers touch UI/backend seams.
10. Ask for participant count and choose main-only or independent branch
    fan-out. Never invent parallel work.
11. Update `CONTROL.md`, `04_workstreams/BOARD.md`, and
    `06_validation/SCORECARD.md`.
12. Commit the coordination baseline before case implementation.

Do not change application code until the journey, architecture, evidence path,
ownership, and execution-mode gates are recorded. Existing repository
instructions always win.
