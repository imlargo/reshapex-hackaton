# AgentSprint control room

This ordinary folder is the portable operational and evidence layer for a
three-to-four-person rapid agent sprint. It may be copied into an unknown
starter repository without renaming or overwriting application files.

Start at `START_HERE.md`. Keep current state only in `CONTROL.md`, current work
only in `04_workstreams/BOARD.md`, and judge evidence only in
`06_validation/SCORECARD.md`. Archive superseded material under `99_archive/`.

The application remains in the host repository's existing source layout.
