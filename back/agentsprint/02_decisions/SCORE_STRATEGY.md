# Score Strategy

Priority: stable demo → visible grounding → central innovation → technical
proof → polish.

| Dimension | Weight | Planned visible evidence |
| --- | ---: | --- |
| Progress | 30% | real model + real tool + cited UI result |
| Innovation | 30% | one selected differentiator inside the main journey |
| Technical checklist | 20% | 3–5 components with tests/traces/UI cues |
| Presentation | 10% | two-minute before/after story + fallback |
| Code quality | 10% | boundaries, locked setup, secrets discipline, milestone history |
