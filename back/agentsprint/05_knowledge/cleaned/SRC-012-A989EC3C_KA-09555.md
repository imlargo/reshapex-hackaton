 Release notes 

 This document contains release notes for Visionary-B Two firmware releases. The latest firmware is version 4.3.3, released in July 2026 .

 Import Notice:  After updating the devices with the latest version, it is not possible to downgrade the firmware to any version 3.x.x ! 

 📥 Download 

 The latest Visionary-B Two firmware is available on sick.com . Please contact SICK support if an older firmware versions is required.

 In addition to the firmware, further software downloads for the related products are available here .

 🧰 Prerequisites 

  📷Supported Hardware 

 The releases listed in this article only support Visionary-B Two devices: V3S146-1x

 ⚙️ Software and system requirements for firmware installation 

 SICK AppManger software tool

 Operating systems:

 Windows 7 (32 bit and 64 bit), Windows 10 or Windows 11

 Ubuntu Linux 14.04, 16.04, 18.04, 22.04 on x86_64 (64 bit)

 Raspian Buster on ARM32 (32 bit)

 1 GHz CPU or comparable and at least 1 GB RAM

 Free hard disk space: 250 MB

 Ethernet: 100 MBit/s or higher. 1 Gbit/s or faster is recommended for best performance during configuration of the device

 🛠️ Installation 

 Please follow the instructions below and carefully read the release notes before starting the installation of the Visionary-B Two firmware.

 🔧 Preparation: Configuration backups 

 Before updating the firmware, ensure your device is powered on and connected to your PC via Ethernet. All installed (Sensor)Apps, their configuration and any licenses will be retained  during the firmware update process. Still please consider the following recommendation:

 💡 Recommended Best Practice:  Use SICK AppManager to create a backup of the installed apps and their configuration. The resulting *.sbpk  file can also be used to duplicate the configuration.

 You can find a how-to video here. 

 🔄 Updating Firmware via Sick AppManager 

 To update the firmware of your device using Sick AppManager , follow these steps:

 Launch Sick AppManager  and ensure your device is connected.

 In the  upper left pane , click  Search devices .

 Double-click the listed  Visionary-B Two  device you want to update.
 💡 We recommend using port  2122  for the connection. 

 The device and app data will now appear in the  lower left pane .

 In the upper right window pane, click on the firmware tab and choose the firmware file (*.spk). If the correct firmware file is not listed click on the ➕ symbol ( Add packages to repository ).

 Finally, click on  install  and follow the on-screen instructions.

 When prompted for credentials, log in using the  Service  user level.
 User:  Service
 Password:  [your custom password]
 💡 If the password has not been changed, the default is:  CUST_SERV

 Hardware documentation 

 Product documentation such as the operating instructions, technical datasheet and mechanical drawings of the Visionary-B Two 3D camera are available on sick.com. 

 Software documentation 

 The Visionary-B Two is a SICK AppSpace device that supports both on-device application execution and data streaming via a GigE Vision interface.

 Devices with P/N 1133032 and P/N 1141229 are delivered with the “Visionary Stream” app pre-installed. This application enables the GigE Vision interface and allows data streaming to a host PC using the GigE Vision API.

 Devices with P/N 1144257 are delivered with the “AI-Assist” app pre-installed.

 If the pre-installed application is removed, the device can be operated using the SICK AppSpace Lua API , enabling direct access to camera functionality through custom applications deployed and executed on the device.

 The following sections describe the operating modes More detailed and provide references to the relevant documentation and API resources.

 GigE Vision Streamer 

 The “Visionary Stream” app enables the GigE Vision interface on the Visionary‑B Two and is required to use the GigE Vision API, including the provided programming examples .

 The “Visionary Stream” app is pre-installed on devices with P/N 1133032 and P/N 1141229.

 The app can be uninstalled or reinstalled as needed using the SICK AppManager .

 The latest version of the “Visionary Stream” app is available in the SICK AppPool .

 Documentation for the GigE Vision API of the Visionary‑B Two is provided within the corresponding software packages available on sick.com .

 AI-Assist 

 The “ AI‑Assist ” app enables AI-based object and person detection on the Visionary‑B Two and provides an integrated solution for environment perception, collision avoidance, and area monitoring. 
 The “AI‑Assist” app is pre-installed on devices with P/N 1144257 (Visionary AI-Assist). 
 The app can be uninstalled or reinstalled as needed using the SICK AppManager. 
 The latest version of the “AI‑Assist” app is available in the SICK AppPool . 
 Documentation and additional resources are provided on sick.com and on the SupportPortal . 

 SICK AppSpace Lua API 

 If no apps are installed on the device, the SICK AppSpace Lua API can be used.

 The SICK AppSpace Lua API provides a comprehensive set of functions for image acquisition, image processing, machine learning, and related utility operations.

 A SICK AppStudio development environment is required to use the SICK AppSpace algorithm API.

 The complete documentation of the available functions is provided in the API Reference Manual (attached to this article) as well as through the code-completion features in SICK AppStudio .
