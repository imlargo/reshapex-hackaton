 Visionary-S CX firmware releases

 Release Notes 

 This document contains release notes for Visionary-S CX firmware releases. The latest firmware is version 6.5.2, released in November 2025.

 Important Notice: No firmware downgrade below version 6.5.2 will be possible after updating devices with the latest version! 

 📥 Download 

 The latest Visionary-S CX firmware is available on sick.com . Please contact SICK support if an older firmware version is required.

 In addition to the firmware, further software downloads for the related products are available here .

 🧰 Prerequisites 

 📷 Supported Hardware and Firmware 

 This release only supports Visionary-S CX devices: V3S102-1x 

 This release is not supported for devices with firmware versions that are older than 5.8.0.

 ⚙️ Software and system requirements for firmware installation 

 We recommend using the latest version of the SOPAS Engineering Tool. You can find the latest version here. 

 For adequate SOPAS ET performance, use a PC with

 Operating systems:

 Windows 10 (64 bit)

 Windows 11

  X86 or x64-compatible processor, minimum: Intel Gen6 or equivalent

 Graphics processor supports OpenGL 4.3 

 Screen resolution 1,024 x 768 or higher, at least 256 colors (65,536 colors recommended)

 Min. 450 MB disk space

 RAM: 1 GB RAM

 Ethernet: 1 Gbit/s or faster is recommended for best performance during configuration of the device via SOPAS ET and for streaming

 🛠️ Installation 

 Please follow the instructions below and carefully read the release notes before starting the installation of the Visionary-S CX firmware.

 🔧 Preparation: Configuration backups 

 Before updating the firmware, ensure your device is powered and connected to your PC via Ethernet. To ensure your device configuration is preserved , please complete the step below before proceeding.

 Save the Configuration 

 Permanently save the current configuration on the device using either SOPAS ET or the respective API command.

 💡 Recommended Best Practice: Write the configuration via the API as part of your application software. This allows for consistent parameterization across devices and automatic setup when integrating new cameras.

 ⚠️ Important Note on SOPAS ET Backups: Configuration files exported via SOPAS ET (*.sopas) are version-specific and cannot be restored on devices running different firmware versions. These backups are not backward or forward compatible, but they can still be useful for manual configuration of devices with the same firmware or as a reference.

 🔄 Updating Firmware via SOPAS ET 

 To update the firmware of your device using SOPAS ET , follow these steps:

 Launch SOPAS ET and ensure your device is connected.

 In the right pane , click Search devices .

 Double-click the listed Visionary-S CX device you want to update.
 💡 We recommend using port 2112 for the connection. 

 The device will now appear in the left pane .

 In the device menu, click Download firmware and follow the on-screen instructions.

 When prompted for credentials, log in using the Service user level.
 User: Service 
 Password: [your custom password] 
 💡 If the password has not been changed, the default is: CUST_SERV 

 After the firmware update completes, install the device driver by selecting Device upload from within SOPAS ET.
 ⚠️ The option "Sick.com or a disk" is currently not supported.

 Known limitations and issues 

 Limitation/Issue 
 Description: 

 Broken SSR file save dialog  
 The file save dialog for recordings (SSR files) occasionally malfunctions in the 64-bit version of SOPAS ET when using an Intel GPU. The 32-bit version is not affected.  

 Incorrect device status indication at low voltage  
 When the device is booted with insufficent voltage, the device LED and the digital result I/O “Device Status” display an incorrect state. The correct state can be found on the device status page in SOPAS ET.

 Release notes firmware version 6.0.0 [Click to expand]

 New features

 Functionality 
 Description 

 Continuous RGB autoexposure 
 A new continuous autoexposure feature has been added for RGB Image which adapts the brightness of the RGB Image without user interaction if the feature is activated 

 Distance modes 
 It is now possible to switch between short and long range mode. Short range: The depth range is limited to 0.5m ... 6.5m and provides sub mm precision. Long range: The working range is increased to 0.5m ... 65m. 

 Error logs on SD cards 
 If a SD card is inserted into the device a log is copied on it which helps to investigate issues with the device. 

 Exposure time range 
 The range for the exposure time was extended down to 1µs in HDR mode 

 Reliability filter range 
 The range of the reliability filter has been increased to allow to weaken the depth validation. 

 Bug fixes

 Bug fix 
 Description 

 DHCP 
 Device streaming stalled under special circumstances when DHCP is used to configure the IP Address of the Device. This has been fixed in this new firmware version. 

 Known limitations and issues

 Limitation/Issue 
 Description 

 Interrupted FW update requires manual reboot 
 In case that a FW update is interrupted (e.g. by user), the device requires a manual reboot 

 Changed IP address due to setting import 
 Importing a .sopas file which changes the IP address requires a camera reboot after the import procedure for completion 

 Color map not saved 
 SOPAS ET does not save the colormap when exporting the visualisation settings.
