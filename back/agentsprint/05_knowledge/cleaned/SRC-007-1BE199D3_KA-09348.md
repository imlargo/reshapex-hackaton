 Inspector83x firmware releases

 Article No: KA-09348

 Version: 20.0

 Subject to change without notice

 Firmware for Inspector83x.

 Related Products

 Inspector83x

 Table of Contents

 Firmware file and installation

 The Inspector83x firmware file is linked to through the Download button at the bottom of this article. The zip file consists of firmware file (.spk), API documentation and release notes.

 Installation

 Use the SICK AppManager  software to update the firmware in a device.
In the SICK AppManager, do the following to update the firmware:

 Connect to the device.

 Clear apps and user data on the device before upgrading to ensure disk space availability (recommended)

 Import the firmware package (*.spk file) to the right pane named “Firmware” using the “Add Packages to repository”/+ button or drag-and-drop.

 Select the firmware package, then press “Install” to start the firmware update.
