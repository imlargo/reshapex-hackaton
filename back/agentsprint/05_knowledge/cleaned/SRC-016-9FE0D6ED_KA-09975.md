 Tutorial SIG300 – Rockwell PLC Integration (1/3) – EtherNet/IP Device Integration

 Article No: KA-09975

 Version: 1.1

 Subject to change without notice

 Learn to integrate SIG300 in Rockwell PLC with an EDS file! Import EDS, add to hardware tree, configure connections, and set up EtherNet/IP. #PLCTutorial

 Related Products

 In this tutorial, we demonstrate how to integrate the SIG300 in a Rockwell PLC environment using an EDS file for seamless setup.

 Learn how to import the EDS, add the SIG300 to the hardware tree, configure connections, and establish EtherNet/IP communication.
