 Release notes 

 This document contains release notes for Visionary-T Mini AP firmware releases. The latest firmware is version 4.3.1, released in May 2026. 

 Import Notice: A downgrade to firmware versions older than 4.3.1 is not supported. 

 📥 Download 

 The latest Visionary-T Mini AP firmware is available on sick.com . Please contact SICK support if an older firmware versions is required.

 In addition to the firmware, further software downloads for the related products are available here .

 🧰 Prerequisites 

  📷 Supported Hardware 

 The releases listed in this article only support Visionary-T Mini AP devices: V3S145-1x 

 ⚙️ Software and system requirements for firmware installation

 Operating systems:

 Windows 7 (32 bit and 64 bit), Windows 10 or Windows 11

 Ubuntu Linux 14.04, 16.04, 18.04, 22.04 on x86_64 (64 bit)

 Raspian Buster on ARM32 (32 bit)

 1 GHz CPU or comparable and at least 1 GB RAM

 Free hard disk space: 250 MB

 Ethernet: 100 MBit/s or higher. 1 Gbit/s or faster is recommended for best performance during configuration of the device

 🛠️ Installation 

 Please follow the instructions below and carefully read the release notes before starting the installation of the Visionary-T Mini AP firmware.

 🔧 Preparation: Configuration backups 

 Before updating the firmware, ensure your device is powered and connected to your PC via Ethernet.

 All installed (Sensor)Apps, their configuration and any licenses will be retained during the firmware update process. Still please consider the following recommendation:

 💡 Recommended Best Practice: 
 Use SICK AppManager to create a backup of the installed apps and their configuration. The resulting *.sbpk file can also be used to duplicate the configuration.

 🔄 Updating Firmware via Sick AppManager 

 To update the firmware of your device using Sick AppManager , follow these steps:

 Launch Sick AppManager and ensure your device is connected.

 In the upper left pane , click Search devices .

 Double-click the listed Visionary-T Mini AP device you want to update.
 💡 We recommend using port 2122 for the connection. 

 The device and app data will now appear in the lower left pane .

 In the upper right window pane, click on the firmware tab and choose the firmware file ( *.spk ). If the correct firmware file is not listed click on the ➕ symbol ( Add packages to repository ). 

Finally, click on install and follow the on-screen instructions.

 When prompted for credentials, log in using the Service user level.
 User: Service 
 Password: [your custom password] 
 💡 If the password has not been changed, the default is: CUST_SERV 

 Release version 4.3.1 

 New Features 

 Functionality 
 Description 

 AppEngine 4.3 
 Update to AppEngine 4.3 to enable latest features of SICK Sensor Apps (e.g. Nova Visionary-T Mini). 

 EtherNet/IP 

 Enabled the EtherNet/IP fieldbus crown.

 New Web UI 

 Introduced a new web‑based user interface that is reachable when no app is installed on the device. It provides toolles access to functions such as downloading the diagnostic file, retrieving the device status, and getting device details.

 LocationName variable 

 Changing the variable LocationName is now only possible while logged in. The default value of the variable has also been updated to "SN <Serial number>".

 Bug Fixes 

 Bug fix 
 Description 

 Incorrect framerate after unexpected reset 

 Fixed issue where the frame rate was incorrectly set to 30 fps after an unexpected reset, even when the application was configured to use a different frame rate.

 Save permanently 

 Fixed issue where permanently saved settings were lost after a power cycle in rare cases.

 Cyber security fix 

 Fixed vulnerability.

 Known limitations and issues 

 Limitation/Issue 
 Description 

 Limited firmware downgrade 
 A downgrade to versions older than 4.3.1 is not supported. 

 Increased switch-on delay 
 At (internal) temperatures below 0°C, the device needs a warm-up phase in order to turn on. Hence, the switch-on delay is increased compared to the ~20 seconds specified for temperatures >0°C. 

 CPU temperature availability 
 The CPU temperature is not available while being below 10°C 

 Change of I/O direction 
 If the direction of a pin changes, the input value can be detected incorrectly and the value will not be corrected despite polling.
Workaround: Release port object, wait 20s, set logic to different value, set logic back to wanted value. 

 No support for 3D Object Detection App 

 The 3D Object Detection app is not supported with this firmware version. To use the app, firmware version 3.15.3 must be installed.

 Release notes firmware version 3.6.0 [Click to expand]

 New features

 Functionality 
 Description 

 Time synchronisation 
 The new PTP crown allows to synchronize the clocks of an arbitrary number of cameras via PTP. This allows for precise timing and offsets between the image acqusition of the individual cameras. 

 FTP server 
 The new FTPServer crown provides FTP server functionality on the device. It complements the existing FTPclient crown. 

 CPU temperature 
 The CPU temperature ia now accessible via API/Cola command alongside other temperature values. 

 Cold start switch-on delay 
 The switch-on delay for cold starts in ambient temperatures between -10°C and 0°C has been reduced. 

 "Reached maximum client connections": TCP socket timeout 
 The default idle time required to automatically close unused sockets was decreased from 2 hours to 3 minutes. Hence, the likelyhood of reaching the maximum number of five client connections (and not being able to open new connections) due to e.g. lost/bad ethernet connection or crashing host applications, has been drastically reduced.
