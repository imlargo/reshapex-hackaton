Highlights of the 2.10.0 release
AI Object Detection tool

Among the many new features we are extra thrilled to present a new AI-powered tool for the Inspector8xx-series; the AI Object Detection tool. 

 

  • AI Object Detection supports on-device training and is suitable for finding features within objects in acquired images. The tool is trained using up to 100 images and is ideal for counting applications. The result is visualized as a point on the detected object.
  • AI Object Detection (dStudio) supports training using the SICK dStudio service and is used to detect (i.e. find) objects in acquired images. The resulting objects are found as bounding boxes which are characterized by their class, size and position.
Nova Dashboard

Another big news is the configurable Dashboard for Nova. The dashboard is easily configured with widgets for e.g. showing sensor data and results in an clean-looking overview.

 

Tool menu with categories

For even easier navigation, the analysis tools have now been sorted into categories in the tool menu.

 

Nova 2D analysis tools for Nova 3D

And that's not all, the 2.10 release also brings a number of Nova 2D analysis tools to Nova 3D, including 1D/2D Code DPM for Nova Ruler3000 and color tools for Visionary-S.

 

Blob Verifier tool for Nova Ruler3000

Talking about new tools for Nova Ruler3000, the 2.10 version adds the Blob Verifier tool, which checks that the found blobs in the image match with a taught set of blobs.

 

Machine Vision Viewer 1.0.0

Besides the update for SICK Nova, we also release a completely new software; Machine Vision Viewer 1.0.0. The software enable easy viewing of saved sensor images, in both 2D and 3D and supports a wide range of formats, including MV3. Download it here.

 

Nova recording tool 1.2.0

We The device scanning is now significantly faster when scanning on a network with several devices connected. Download it here.

 

Machine Vision ZIP .NET SDK 1.1.0

There is an official SDK for .NET to both simplify integration for other SICK products and for customers using the MVZ format. MachineVisionZip SDK for .NET 1.1.0. Download it here.

Nova Ruler3000 IPC

There is now an IPC solution for SICK Nova to run with Ruler3000. With the specific Nova Ruler3000 IPC SensorApp running on SICK AppEngine, the Ruler3000 enable high performance quality control applications to be solved in unmatched speed.

  • Sensor Connection
    The tool Sensor Connection scans for and connects to a Ruler3000 camera.

  • Acquisition settings for Ruler3000
    The Acquisition section contains settings for the Ruler3000 camera, such as configuring the laser detection, image trigger, motion, and field of view.

  • Configurable dashboard for operator UI
    A configurable dashboard with widgets for e.g. showing sensor data and results has been added.

  • Many 2D and 3D analysis tools
    See full release notes for details.
