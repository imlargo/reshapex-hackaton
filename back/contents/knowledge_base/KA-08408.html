Introduction



The OpenAPI specification is an HTTP API specification language that provides a standardized means of defining an API. You can quickly discover how an API works, configure infrastructure, and generate client code.
You can read the device variables using the given OpenAPI file. After installing the Insomnia and the plugin, which manages challenge-response authentication in combination with the specified Insomnia environment, you even write device variables and execute device methods.

How to write/post variables with a Python example

To prevent unauthorized access, the HTTP interfaces underlies an Challenge-response process. It is a participantïs secure authentication process based on knowledge. For this purpose, a participant poses a challenge to which others have to respond in order to prove that he or she knows a certain shared secret without having to transmit this information themselves. This is protection against a password from being listened to by attackers on the line.
You can either use Insomnia in combination with the given plug-in (see video above) or you can check out this Python example: https://github.com/SICKAG/sick_scan_rest_client

Where to find the OpenAPI-file
The files are now available on www.sick.com under the download section of the appropriate device.
